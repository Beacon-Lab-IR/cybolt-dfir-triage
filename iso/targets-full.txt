# ==============================================================================
#  Cybolt DFIR — targets-full.txt
#  Lista exhaustiva de KAPE targets para IR con sospecha de operador interno /
#  retraso de software / actividad de usuario en ventana temporal acotada.
#
#  Compatible con: KAPE 1.3.0.2 (kape.exe) y compound KapeTriage.
#  Tamano bundle esperado: ~5-15 GB (Tier 1+2+3), ~10-25 GB (todos los tiers).
#
#  USO:
#    1. Descargá este archivo del repo (o del ISO montado como CD-ROM).
#    2. Stage a disco writable en la victima (NO correr kape.exe desde CD-ROM):
#         xcopy /E /I /Y D:\KAPE C:\KAPE      (ajustar letra del ISO)
#         copy /Y targets-full.txt C:\KAPE\
#    3. Ejecutar (CMD como Administrador):
#
#         C:\KAPE\kape.exe ^
#           --tsource C:\ ^
#           --target KapeTriage ^
#           --targets-list C:\KAPE\targets-full.txt ^
#           --tdest E:\HOSTNAME-YYYYMMDD-HHMMSS\ ^
#           --targetdir C:\KAPE\Targets ^
#           --zip E:\HOSTNAME-YYYYMMDD-HHMMSS\HOSTNAME-KAPE-YYYYMMDD-HHMMSS ^
#           --hv nc,vm ^
#           --vss
#
#  ORDEN DE VOLATILIDAD (obligatorio):
#    1. RAM primero: winpmem_mini_x64_rc2.exe E:\HOSTNAME-...\memory.raw
#    2. Recién despues este KAPE.
#
#  FILTRO POR TIEMPO (T1..T2):
#    KAPE no filtra por tiempo en adquisicion — adquiere todo.
#    El filtrado se hace POST-adquisicion con EZTools:
#      EvtxECmd    -d "YYYY-MM-DD..YYYY-MM-DD"
#      MFTECmd     --date "YYYY-MM-DD..YYYY-MM-DD"
#      PECmd       --date "..."
#      JLECmd      -d "..."
#      AmCacheParser  (filtro por KeyLastWriteTimestamp)
#      RegistryExplorer  (vista Timeline / LastWriteTime)
#
#  NOTAS:
#    - NO usar --sync (bug KAPE en proceso interpreta $Null como filename).
#    - --vss requiere elevacion a Administrator.
#    - KapeTriage ya cubre BasicCollection + EventLogs + RegistryHives +
#      Prefetch + AmCache + PowerShell + ScheduledTasks + Services + AppCompat
#      + LNKFilesAndJumpLists + EvidenceOfExecution + $MFT + $LogFile + $UsnJrnl.
#      KAPE deduplica por hash, listarlos igual es red de seguridad.
# ==============================================================================
